## Findings considered and rejected

- `cargo audit` quick-xml advisories (RUSTSEC-2026-0194/0195): reached only
  through `zbus_xml` (D-Bus introspection XML from atspi) and the build-time
  `wayland-scanner` proc-macro, both parsing trusted XML. Not exploitable;
  will clear when atspi/wayland-scanner bump. Not worth a plan.
- `SECURITY-07` `transfer_id` in temp path: fused onto a fixed prefix in the
  first path component; not exploitable today. Cosmetic consistency only.
- Merging the three bun projects into one workspace (`DEBT-22`): separate
  lockfiles are deliberate because `runtime/cua-node` consumes the other two
  as packed artifacts. Not worth doing.
- Splitting the two largest Python smoke harnesses by size alone: single-purpose
  VM drivers with little cross-file churn; `DEBT-21` helper extraction is the
  better lever.
- Removing the Legacy browser-control mode: it is still the default when
  unset; the migration is in progress, not finished.
- Managed browser profile, macOS backend, arm64 release, consumer action
  broker, multi-sandbox fleet: no repo evidence of demand; several are
  explicitly deferred in `ROADMAP.md` / `docs/research`.
- `PERF-15` moving instead of cloning tool results: sub-millisecond; fold
  into any future `mcp_tools.rs` dispatch refactor (`DEBT-11`) rather than
  plan separately.
- `PERF-13/14/17` (resize cost, persistent PipeWire pipeline, 500 ms XTest
  settle): LOW confidence, measure-first items; not planned until there is a
  number.
