## Findings considered and rejected (do not re-audit)

- **chrome-host `process::exit(1)` on Chrome-pipe write error** — by design;
  documented rationale at `crates/sky-cua-chrome-host/src/host.rs:278-283`
  (dead port is terminal; exit produces a clean disconnect).
- **Header-only PNG dimension parse for phone captures** — rejected fix: the
  full decode in `decode_png_dimensions` is a deliberate truncation/integrity
  gate (doc comment at `phone/manager/capture.rs:418`). The real waste is the
  *second* decode; addressed correctly in plan 006.
- **Dependency version lag (wgpu/zbus/atspi/smithay/tokio/AGP/Gradle)** —
  checked; pins are current as of 2026-07. No action.
- **Duplicate transitive crate versions** (hashbrown/getrandom/winnow etc.) —
  diamond skew, all transitive, resolves with ecosystem convergence. Not
  worth chasing.
- **`[profile.release]` tuning slowing dev builds** — does not apply; no
  `[profile.dev]` override exists, dev builds use defaults.
- **scripts/ sprawl (103 files)** — already mitigated by `scripts/AGENTS.md`
  index + `_`/`live_`/`test_` naming discipline.
- **Overlay idle redraw at panel refresh while visible-but-settled**
  (`layer_shell.rs:555-575`) — deferred, not planned: the ambient edge
  glow/inward wave may be intentionally continuously animated; needs a
  maintainer call on idle-glow cadence before it's a finding.
- **Portal session startup prewarm** — deferred: prewarming before user
  context is ready risks a spurious approval prompt; needs a restore-token
  interaction check first.
- **Chrome-host rollout drain holds mutex across file I/O**
  (`host.rs:408-446`) — real but low-leverage; revisit if browser routing
  latency spikes appear.
- **Input-helper `SO_PEERCRED` check** (`input-helper/server.rs:54`) — valid
  defense-in-depth finding (MED confidence, conditional on shared-group
  installs), but the project's explicit stance deprioritizes security
  hardening, so the advisor left it unplanned this round. S-effort if
  ever picked up: mirror the peer-cred check at
  `chrome-host/host.rs:630-670`.
- **X11 targeted-crop scale-1 assumption** (`capture_plan.rs:468-475`) —
  investigate-tier; correct for the common unscaled case, no observed
  failure. Revisit if HiDPI-X11 targeting misses appear.
- **COSMIC multi-monitor absolute-pointer bounds** (first-output-only,
  `virtual_input.rs:1537`) — real but contingent on multi-monitor COSMIC
  with the helper route; no plan this round. Fix shape: virtual-desktop
  union across `cosmic-randr` outputs.
- **MCP fixture self-regeneration risk** (`SKY_CUA_UPDATE_MCP_FIXTURES`) —
  process risk, not a bug; mitigation noted in plan 009's maintenance notes.
- **`.editorconfig` / pre-commit hooks** — declined as standalone items;
  pre-commit is noted as deferred in plan 001.
- **Cached IPC stream discards BufReader read-ahead**
  (`service_launcher.rs:367-374`) — latent hazard only; the daemon's strict
  one-response-per-request invariant makes it safe today. Revisit if the
  wire protocol ever pipelines.
