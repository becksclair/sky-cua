# Phone Use

Use direct `sky_cua` Phone tools for a short stateless action. Use persistent `node_repl` with `@heliasar/sky-cua/phone` for a retained device session, screenshots and image emission, local-file workflows, or composed Browser/Computer/Phone work.

Read `references/node-repl.md`, then `references/phone.md`. A bound device session never silently reconnects after disconnect and mutation calls are never retried after an ambiguous write.

Task recipes: `recipes/phone-workflows.md` and `recipes/composed-workflows.md`.
